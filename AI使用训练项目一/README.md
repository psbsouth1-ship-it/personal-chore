# personal-chore

高精度计算器：自研大数内核的 C++17 程序，无第三方依赖。
输入一串算式，支持四则运算与指数/对数运算。

## 输入限制

- 单个输入数字：`|x| <= 2^8 = 256`
- 计算结果：`|y| <= 2^10 = 1024`
- 超出范围会报错并指出原因

## 设计

数值统一用**定点十进制**表示：

```
值 = 带符号大整数 / 10^SCALE
```

`SCALE` 为小数位数（默认 60，可用 `-p` 调整）。
因为整数部分至多 4 位，配合 60 位小数共有约 64 位有效数字，精度充裕；
同时避开了二进制换算与保护位逻辑，实现更简单。

## 文件结构

| 文件 | 作用 |
|------|------|
| `bigdec.hpp` / `bigdec.cpp` | 十进制大整数：加、减、乘、Knuth 长除、整数开方、数字组转换 |
| `fixdec.hpp` / `fixdec.cpp` | 定点十进制：四则、取整、解析/输出、范围校验 |
| `scientific.hpp` / `scientific.cpp` | `sqrt` / `cbrt` / `root`、`ln` / `exp`、幂、阶乘 |
| `parser.hpp` / `parser.cpp` | 词法分析 + 递归下降求值 |
| `main.cpp` | 命令行入口（单次计算 + 交互模式） |

## 构建与运行

```sh
# 推荐直接用脚本（已处理中文编码）
build.bat

# 或手动编译
g++ -std=c++17 -O2 -fexec-charset=GBK -o calc.exe ^
    main.cpp parser.cpp scientific.cpp fixdec.cpp bigdec.cpp
```

> `-fexec-charset=GBK` 让程序内嵌的中文与 Windows 控制台默认代码页
> （GBK/936）一致，避免中文乱码。若改用 `chcp 65001`，则去掉该选项。

```sh
calc.exe "2^10"            # 单次计算
calc.exe -p 100 "1/3"      # 指定小数位数
calc.exe "7^(1/3)"         # 立方根可用分数指数
calc.exe                   # 交互模式（输入 help / quit）
calc.exe --help            # 帮助
```

## 示例

单次计算会**先回显算式、再输出结果**：

```
$ ./calc "7*7"
7*7
= 49

$ ./calc "7^(1/3)"
7^(1/3)
= 1.912931182772389101199116839548760282862439050345875766210652

$ ./calc "(2+3)*4"
(2+3)*4
= 20

$ ./calc "1/3"
1/3
= 0.333333333333333333333333333333333333333333333333333333333333

$ ./calc "sqrt(2)"
sqrt(2)
= 1.41421356237309504880168872420969807856967187537694807317668

$ ./calc "cbrt(-8)"
cbrt(-8)
= -2
```

超出限制时也会先回显算式，再给出错误说明：

```
$ ./calc "300"
300
错误: 输入数字 超出允许范围（|值| <= 256）

$ ./calc "2^11"
2^11
错误: 幂运算结果 超出允许范围（|值| <= 1024）
```

交互模式（算式已显示在 `>` 提示行，因此只输出结果）：

```
$ ./calc
高精度计算器（输入 help 查看用法，quit 退出）
> 7*7
= 49
> 7^(1/3)
= 1.912931182772389101199116839548760282862439050345875766210652
> quit
```

## 验证情况

用 Python `decimal`（`getcontext().prec = 64`）交叉验证：

- `bigdec`：大数加减乘、`10^50/3`、`2^100`、`isqrt`、舍入、十进制↔二进制往返 —— 全部一致
- `fixdec`：`1/3`、`2/7`、`355/113`、`0.1+0.2`、取整族 —— 60 位小数全部一致
- `scientific`：`pi`、`e`、`ln(2)`、`ln(10)`、`ln(256)`、`exp(1)`、`exp(2)`、`exp(-1)`、
  `sqrt(2)`、`log2(256)`、`log(8,2)` —— 60 位小数全部与 Python 一致
- 精确值：`sqrt` / `cbrt` / `root` / 整数指数幂（如 `2^10 = 1024`、`3^4 = 81`）
- 端到端：正常算式 + 错误用例 + `-p` 选项 + 交互模式 —— 全部符合预期
- 输出格式：单次计算回显算式后输出 `= 结果`；错误与结果顺序一致

## 实现要点

- **长除法**：Knuth 算法 D（`bigdec.cpp` 的 `divDec`），单位 `10^9`
- **开方**：十进制精确整数平方根（`isqrt`）+ 放大后取根
- **`ln`**：归一化到 `m ∈ [1,2)`，用 `ln x = e·ln2 + 2·atanh((m-1)/(m+1))` 级数
- **`exp`**：先用 `x = k·ln2 + r` 缩减范围，再对 `r` 用泰勒级数，最后乘 `2^k`
- **整数指数幂**：走快速幂，结果为精确值；非整数指数才走 `exp(y·ln x)`
